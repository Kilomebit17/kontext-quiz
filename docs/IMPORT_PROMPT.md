# Промпт для генерації файлу імпорту вікторини

Скопіюй текст нижче в будь‑який AI‑асистент, підстав тему та кількість запитань, збережи відповідь як
`.csv` (UTF‑8) і завантаж у Kontext Quiz: **Мої вікторини → Імпорт із CSV/XLSX** (або в редакторі вікторини).

---

```text
Створи файл для імпорту вікторини у форматі CSV. Тема: «{{ТЕМА}}». Кількість запитань: {{N}}.
Мова запитань і відповідей: українська.

Суворі правила формату (від них залежить, чи файл прочитається):
1. Розділювач полів — крапка з комою «;». Один рядок = одне запитання.
2. Перший рядок — заголовок, рівно такий:
   question;option1;option2;option3;option4;correct;time
3. Колонки в кожному рядку:
   - question — текст запитання, до 120 символів, без переносів рядка.
   - option1..option4 — варіанти відповідей, до 75 символів кожен. Мінімум 2 варіанти;
     якщо варіантів менше чотирьох, залиш порожні комірки (наприклад: «;;»).
   - correct — номер правильного варіанта (1–4). Якщо правильних кілька — номери через кому
     без пробілів, наприклад «1,3». Питання з кількома правильними відповідями зараховуються
     повністю лише при виборі всіх правильних варіантів.
   - time — час на відповідь у секундах, одне з: 5, 10, 20, 30, 60, 90, 120.
4. Не використовуй «;» усередині тексту запитань чи варіантів. Не використовуй лапки навколо
   значень. Не додавай нумерацію запитань у текст. Жодних порожніх рядків між запитаннями.
5. Для запитань «Так / Ні» дай рівно два варіанти: «Так» і «Ні» — вони автоматично стануть
   типом «Правда / Брехня».
6. Правильні відповіді мають бути в різних позиціях (не завжди option1).
7. Виводь ТІЛЬКИ вміст файлу без пояснень, без markdown‑обгортки і без тексту до чи після.

Приклад (3 рядки для орієнтиру, не включай їх у відповідь):
question;option1;option2;option3;option4;correct;time
Яка річка є найдовшою в межах України?;Дністер;Дніпро;Південний Буг;Десна;2;20
Які з цих міст розташовані в Україні?;Одеса;Варшава;Харків;Прага;1,3;30
Дніпро впадає в Чорне море?;Так;Ні;;;1;10
```

---

## Що ще підтримує імпорт

- Розділювач визначається автоматично: `;` або `,`. Якщо AI видав файл із комами, він теж
  прочитається, але тоді коми не можна вживати всередині тексту.
- Замість номерів у колонці `correct` можна писати літери `A`–`D`.
- Заголовок можна пропустити, але з ним надійніше.
- `.xlsx` теж підходить: ті самі 7 колонок у першому аркуші.
- Час, якого немає в списку (наприклад 15), округлюється до найближчого дозволеного.
- Медіа (зображення/YouTube), інфослайди, текстові відповіді та ×2 бали імпорт не підтримує:
  додай їх у редакторі після імпорту.

Рядки з помилками (без запитання, менше двох варіантів, некоректний `correct`) пропускаються, а
редактор показує попередження з номером рядка.
